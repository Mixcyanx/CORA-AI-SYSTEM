## About CORA AI

**CORA AI** 是一套以人工智慧為核心的智慧藥物解說系統。

使用者可以直接用自然語言詢問藥物相關問題，系統會結合 AI 與藥物知識資料，將複雜的藥物資訊轉換成較容易理解的內容。

支援電腦、平板與手機，可直接透過瀏覽器使用。
